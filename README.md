# Real-Time Quiz Application

## 🚀 Project Overview
A web-based real-time quiz application that allows admins to create quizzes and participants to join using a QR code or link. The system displays questions with a timer and shows a live leaderboard.

## ✨ Features
- Admin dashboard to create and manage quizzes
- QR Code & link-based quiz access
- Timer-based question flow
- Real-time leaderboard
- Sound effects for correct/wrong answers
- Winner announcement with confetti
- Previous quizzes history page

## 🛠 Tech Stack
- Frontend: React.js
- Backend: Node.js, Express.js
- Database: MongoDB
- Real-time: Socket.IO
